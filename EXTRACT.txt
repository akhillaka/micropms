MicroPMS — extract this zip on Hostinger
========================================

1. hPanel → File Manager → open the DOMAIN folder
   (the parent of public_html, not public_html itself).

2. Upload this zip there. Extract. You must see siblings:

     .env                 (create once; never overwrite)
     public_html/         (web root)
     pms_core/
     db_migrations/

   Wrong: public_html/public_html  or  public_html/pms_core

3. Do not replace existing:
     .env
     public_html/uploads/
     pms_core/uploads/

4. If .env does not exist yet, copy .env.example to .env in this
   same folder and fill DB_* plus INVOICE_SECRET.
   Use paths on this host: /login /admin /guest-login /assistant /saas-admin.

5. PHP 8.1+ with pdo_mysql, curl, mbstring, openssl.

6. Open https://YOUR-HOST/admin/run_migration and click Run
   (log in first at /login). This applies 029–034 (gateways, guest ID,
   schema alignment, service-request channels, room DND, staff PWA push).

Staff / guest / SaaS (same host, no subdomains):
  https://YOUR-HOST/login
  https://YOUR-HOST/admin
  https://YOUR-HOST/saas-admin
  https://YOUR-HOST/guest-login
  https://YOUR-HOST/assistant
